# Behavioral activation app (prototype)

_Name not decided yet._

A clickable, mobile-first prototype of a gentle behavioral-activation app. It helps people with low energy do everyday things by breaking tasks into very small steps.

## Run it

Open `index.html` in a browser. No build step and no backend. For the best view, use a phone or a narrow window (about 390px wide).

## What's in it

- Opening moment with rotating kind messages
- Home with "Today's small things" and the next small step
- Add a task by typing or with a simulated voice screen
- Split screen: break a task into steps, tap "Smaller!" to break them down further, "Bigger" to go back
- A calm moment after each step, with an optional mood check
- A pixel-art gallery that only grows
- Settings for notifications, private learning, and a trusted contact
- A "Need help now?" support screen

Task splitting uses mock data, not a live AI model. All state is kept in memory and resets on reload.
